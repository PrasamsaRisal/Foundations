# Foundations
A learning project that explores HTML and CSS.
# Overview
This project explores the concept of flexbox along with alignment and margin styling. It is built as a learning foundation for understanding how HTML and CSS work together.
# Features
### Flexbox
The main concept explored in this project is flexbox. It helped with arranging images, text, and links in a cleaner layout.
### Margins
Different margin values are used to adjust elements for a better design.
# How to use
1. Clone the repository to your local machine.
2. Open the `index.html` file in your browser.
3. Use Live Server if you want the page to refresh automatically while you edit.

# Notes
To understand the CSS file better, learn the basics of styling and how flexbox works.
